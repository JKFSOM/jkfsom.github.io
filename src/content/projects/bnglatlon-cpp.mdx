`bnglatlon-cpp` converts British National Grid (OSGB36) coordinates to approximate latitude and longitude (WGS84). It is a C++ implementation of one function from the Python module [fmalina/blocl-bnglatlon](https://github.com/fmalina/blocl-bnglatlon), packaged as a Python extension.

## Results

In a local benchmark on four valid grid points, the C++ version took about 92% less elapsed time per conversion than the pure-Python version without Numba.

| Item   | Elapsed time per conversion (µs) |
| ------ | -------------------------------- |
| Python | 8.54                             |
| C++    | 0.71                             |
